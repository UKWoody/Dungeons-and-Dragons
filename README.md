# The Obelisk Sage

A Foundry VTT module containing three powerful D&D 5e artifacts:

## Contents

### Artifacts

- **The Black Oracle** - An artifact that grants darkvision, guidance through oracle consultation, and surprise prevention
- **The Crimson Visage** - A vampiric helm granting darkvision, predatory instincts, and damage avoidance
- **The Infernal Choker of Bel** - An infernal artifact requiring Warlock attunement, granting psychic resistance and strategic insights from Bel

## Installation

1. In Foundry VTT, go to **Add-on Modules**
2. Click **Install Module**
3. Paste this URL: `[your-module-url]`
4. Click **Install** and enable the module in your world

## Usage

All items are available in the **Artifacts** compendium. Drag them into your world or character sheets to use them.
